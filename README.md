# Discord Component-Driven Message JSX Runtime

This is a simple JSX runtime that I've put together to simplify constructing and maintaining component-driven messages for Discord bots.  The intent is to create a React-like workflow for bot development and maintenance.

You can construct messages, modals, and reusable message elements in JSX, and they'll be rendered into the JSON structures used in when sending or updating component-driven messages in the Discord API.
